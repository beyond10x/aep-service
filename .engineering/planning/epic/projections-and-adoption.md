# Epic: Projections and adopter migration

## Outcome

Repositories and company-wide readers receive authorized, deterministic views of one canonical
service record, while Jira remains an explicitly sourced intake system.

## Scope

Consistent snapshots, projection manifests, Markdown adoption, cross-repository graph queries and
Jira report ingestion. Rendering remains EP's responsibility.

## Done When

One adopting repository has no canonical Markdown write path, its generated tree passes drift
checking, and authorized users can traverse dependencies across repository workspaces.

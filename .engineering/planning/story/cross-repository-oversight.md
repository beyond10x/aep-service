## Context

Central authority earns its cost only if dependencies and objective chains no longer stop at the
current repository's planning directory.

## Acceptance

An authorized query returns incoming and outgoing dependencies, blockers and objective chains across repository workspaces using canonical identities while preserving each workspace's access rules.
